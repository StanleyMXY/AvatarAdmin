## 四、不是缺陷

3. **轮询时已经打开的行内确认、表格遮罩、读失败。** 我查了三项，都没有问题，见第一节第 2 条，不用再查。
4. **`?tab=` 的约定。** 见第一节第 5 条：取值写在问题文件和代码里了，进规格是负责人的事。如果希望其他模块的作者也在“约定”文件里看到，可以在 `execution-conventions.md` 里加一行，这是负责人的选择，不是缺失。
5. **漏斗页的 150 毫秒等待用来证明“没有请求”。** 测试里（`funnel.test.tsx` 的清除选择、不合法、另存三条）用固定等待后断言请求数没增加，这是证明“没发生”的常见做法，加上变异“把自动查询去掉”能让十一条变红，已经足够。
